# 自律锁 · FocusLock

打开抖音之前，先答一道针灸推拿的填空题。答对、看完解析、点「进入」——才放你进去。

一个自用的安卓小工具，把 **4150 道专业课填空**做成抖音的门槛。题库内置在 APK 里，离线可用。

## 功能

| 功能 | 说明 |
| --- | --- |
| 填空题闸门 | 打开被锁应用弹出答题页，1～2 个空，输入答案才判 |
| 分类 / 科目 | 随机 / 基础题 / 重点题 / 难点题 / 真题模拟；20 个科目可选，默认随机 |
| 3 次机会 | 每答错一次从今日额度扣 5 分钟，3 次用完当次进不去 |
| 解析 + 确认进入 | 答对后先看答案和解析，点「看完了，进入应用」才放行 |
| 错题记忆 | 3 次没答对的题会记住，下次进来先补，答对才清除 |
| 每日额度 | 15～120 分钟，用完当天只能退到桌面 |
| 刷题模式 | 把题库当练习刷，统计今日对错 |
| 检查更新 | 应用底部一键检查，直接下载并调起安装器 |
| 防卸载 | 设备管理器授权，卸载前要先取消 |

## 安装后的三步

1. **开启无障碍服务**：系统设置 → 无障碍 → 自律锁。Android 13+ 若开关是灰的，去 `设置 → 应用 → 自律锁 → 右上角 ⋮ → 允许受限制的设置`。
2. **授予「显示在其他应用上层 / 后台弹出界面」**：不然答题页盖不到抖音上面。
3. **确认锁定的应用**：首次启动自动勾选抖音，可在「管理应用」里改。

国产系统建议再把自律锁设成「允许后台运行 / 自启动」，否则无障碍服务会被系统杀掉。

## 更新机制

应用底部「检查更新」会依次尝试这几个地址读取 `update.json`：

```
https://ghproxy.net/https://raw.githubusercontent.com/wangji330330-ops/117/main/
https://gh-proxy.com/https://raw.githubusercontent.com/wangji330330-ops/117/main/
https://raw.githubusercontent.com/wangji330330-ops/117/main/
https://cdn.jsdelivr.net/gh/wangji330330-ops/117@main/
```

哪个先通就用哪个，并且用同一个镜像去下 APK——所以国内网络下也能更新。

发现了新版本时：

1. 弹窗显示版本号和更新说明
2. 点「立即更新」→ 下载到应用缓存
3. 自动调起系统安装器 → 覆盖安装（配置和题库筛选都保留）

首次更新需要允许「自律锁 → 安装未知应用」，应用会自动跳到那个设置页。

**发布新版本的做法**：

1. 新包**换个文件名**，带上版本号，例如 `focuslock-1.6.apk`（镜像会按 URL 缓存几分钟，换名能保证拿到新包，别原地覆盖同名文件）
2. 更新 `update.json`：
   - `versionCode` +1（App 靠它判断新旧）
   - `versionName` 改成新版本号
   - `apk` 改成新文件名
   - `size`、`sha256` 换成新包的实际值
   - `notes` 写更新说明
3. 把两个文件一起提交

App 会依次读取镜像，命中哪个就用哪个下载，所以国内网络也能更新。

## 关于权限

| 权限 | 用途 |
| --- | --- |
| 无障碍服务 | 判断当前前台是哪个应用（只取包名，不读屏幕内容、不记录输入） |
| 悬浮窗 / 后台弹出 | 把答题页盖到被锁应用上面 |
| 网络 | 仅用于「检查更新」访问 GitHub，不上传任何数据 |
| 安装未知应用 | 下载更新后调起安装器 |
| 设备管理器 | 防卸载（可选） |

题库和所有设置都存在本机，没有账号、没有服务器。

## 已知限制

- 不是系统级：强杀进程、在设置里关掉无障碍都能绕过。它拦的是「顺手」，拦不住「铁了心」。
- 只按前台应用判断，分屏 / 小窗 / 画中画可能识别不到。
- 更新依赖 GitHub 可达性；镜像全挂的时候只能手动装 APK。
- 题库「解析」来自原始题库表，个别题的判定可能偏严。

---

## 题库分类的来历

题目来自 `题库总表_可筛选.xlsx`（4150 题 / 20 科）。原表没有「基础/重点/难点」字段，但命题规格写明每批按 **基础 30% / 重点 30% / 难点 20% / 病案（真题模拟）20%** 顺序生成，按「批内位置」还原后正好 1245 / 1245 / 830 / 830，且「真题模拟」那档 84% 含患者病案、题干明显更长，可确认还原正确。

> 源数据里「模拟题」和「真题」是同一批，所以合并成了一个选项「真题模拟」。
