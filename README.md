## 这是什么

手机上瘾的解法通常有两种：要么彻底卸载，要么全靠意志力。这两条都很难坚持。

这个工具走第三条路：**不拿走抖音，只在门口放一道题。**

你打开抖音 → 弹出一道针灸推拿的填空题 → 答对、看完解析、点「进入」→ 才放行 5 分钟。答错要扣时间，连错三次就得退出。

题库是 4150 道填空，覆盖 20 个科目，内置在 APK 里，离线可用。也就是说：**你每刷一次视频，都得先复习一个考点。**

## 安装：三步

**1. 开启无障碍服务**

系统设置 → 无障碍 → 自律锁 → 打开。

Android 13 以上如果开关是灰的：`设置 → 应用 → 自律锁 → 右上角 ⋮ → 允许受限制的设置`，再回来打开。

**2. 授予悬浮窗 / 后台弹出权限**

应用权限里找「显示在其他应用上层」或「后台弹出界面」。没有这个权限，答题页盖不到抖音上面。

**3. 确认锁定的应用**

首次启动会自动勾选抖音。要加别的（B 站、小红书、游戏）去「管理应用」里勾。

> 国产系统（小米 / 华为 / OPPO / vivo）建议再把自律锁设成「允许后台运行 / 自启动」，否则无障碍服务会被系统清理掉。发现突然不拦了，回来重新打开一次无障碍即可。

## 关于题库

题目来自 `题库总表_可筛选.xlsx`：**4150 题 / 20 科 / 82 批**。

原表没有「基础 / 重点 / 难点」字段，但命题规格写明每批按 **基础 30% / 重点 30% / 难点 20% / 病案（真题模拟）20%** 顺序生成。按「批内位置」还原后正好 1245 / 1245 / 830 / 830，且「真题模拟」那档 84% 含患者病案、题干明显比其他档长——可以确认还原正确。

> 源数据里「模拟题」和「真题」是同一批（规格原文就是「病案（真题模拟）」），所以合并成了一个选项。

判题做了容错：忽略空格、全角半角、中英文标点；`大指次指（食指）` 只写「食指」算对；`足太阳膀胱经` 写「膀胱经」算对；纯数字答案必须精确（防止 `36` 蒙中 `361`）。4150 道题已用脚本全量回归过。

## 常见问题

**Q：为什么不用简单的闹钟 / 番茄钟？**
A：闹钟按一下就关了。这里要求你真的答对一道专业课的题——至少得动脑。

**Q：答错了真的扣时间吗？**
A：扣的是「今日已用额度」。如果把每日额度设成「不限」，扣时只记录、不封顶。

**Q：会不会偷看我的屏幕？**
A：不会。无障碍服务只读取**当前窗口所属的应用包名**，用来判断你在用哪个应用。不读界面文字、不记录输入、不上传任何数据。题库和设置全部存在本机。

**Q：装了之后发现不拦了？**
A：多半是无障碍服务被系统杀了。回应用里重新打开一次；长期解决见上面「安装第三步」的保活设置。

**Q：能多锁几个应用吗？**
A：可以，管理应用里随便勾。规则是全局统一的。

## 已知限制

- 不是系统级：强杀进程、关掉无障碍都能绕过。它拦的是「顺手」，拦不住「铁了心」。
- 只按前台应用判断，分屏 / 小窗 / 画中画可能识别不到。
- 更新依赖 GitHub 可达性；镜像全挂的时候只能手动下 APK。
