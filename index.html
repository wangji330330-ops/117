这是什么

戒手机的办法通常两种：卸载，或者靠意志力。两条都难坚持。

这个工具走第三条：不拿走抖音，只在门口放一道题。
你打开抖音 → 弹出一道专业课填空 → 答对、看完解析 → 才放行 5 分钟。
题库 4150 道，20 个科目，内置在安装包里，离线可用。

换句话说：每刷一次视频，先复习一个考点。

长这样

经络与腧穴 · 基础题
内踝上8寸以下，足厥阴在前、足太阴在中、______ 在后。
空1 · 在这里填写答案
今日还可答错 2 次 · 每次答错扣 5 分钟
答对了
答案：足少阴
解析：内踝上8寸是足厥阴与足太阴交叉处，交叉前后两经前后位置互换。
［ 看完了，进入应用 ］

功能

填空闸门　打开被锁应用就弹题，1～2 个空，输入答案才判
分类与科目　基础 / 重点 / 难点 / 真题模拟，20 个科目可选，默认随机
限时放行　答对后 3～60 分钟，到点重新出题
3 次机会　每答错一次从今日额度扣 5 分钟，用完当次进不去
解析 + 确认　答对先给答案和解析，点「进入」才放行
错题追着走　3 次没答对的题会记住，下次先补这一道
每日额度　15～120 分钟，用完当天只能退到桌面
刷题模式　不拦应用，单纯把题库当练习刷
检查更新　应用内一键更新，自动选线路下载
守护开关要答题　开启守护得先答对 10 道题（分类/科目自己挑）；关闭前先摆出今天的成绩，再答对 2 道才生效
防卸载　设备管理器授权，卸载前要先去设置取消

装好之后（三步）

  1. 开启无障碍服务：设置 → 无障碍 → 自律锁 → 打开。
    Android 13 以上如果开关是灰的：设置 → 应用 → 自律锁 → 右上角 ⋮ → 允许受限制的设置。
  2. 给「显示在其他应用上层 / 后台弹出界面」权限：没有这个，答题页盖不到抖音上面。
  3. 确认锁定的应用：首次启动会自动勾选抖音，要加别的去「管理应用」里勾。

国产系统建议再把自律锁设成「允许后台运行 / 自启动」，否则无障碍服务会被系统清理。发现突然不拦了，回来重新打开一次即可。

常见问题

  1. 会不会偷看我的屏幕？
    不会。无障碍服务只读取当前窗口所属的应用包名，用来判断你在用哪个应用。不读界面文字、不记录输入、不上传任何数据。题库和设置全部存在本机。
  2. 答错真的扣时间吗？
    扣的是「今日已用额度」。如果把每日额度设成「不限」，扣时只记录、不封顶。
  3. 能多锁几个应用吗？
    可以，管理应用里随便勾。规则是全局统一的。
  4. 装了发现不拦了？
    多半是无障碍服务被系统杀了，回应用里重新打开一次。

已知限制

不是系统级工具：强杀进程、关掉无障碍都能绕过。它拦的是「顺手」，拦不住「铁了心」。
只按前台应用判断，分屏 / 小窗 / 画中画可能识别不到。
